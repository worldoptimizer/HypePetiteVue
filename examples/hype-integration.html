💡 Key Concepts Demonstrated

  • createHypeStore() - Creates reactive store with Hype API access
  • $hype.showScene() - Navigate between scenes with transitions
  • $hype.startTimeline() - Start timeline animations
  • $hype.pauseTimeline() - Pause running timelines
  • $hype.continueTimeline() - Resume paused timelines
  • $hype.setElementProperty() - Animate element properties (rotation shown)
  • Reactive Integration - Vue state triggering Hype animations

🚀 Using in Real Hype Projects

In a real Tumult Hype document, you would:

  1. Add <script src="HypePetiteVue.js"></script> to Head HTML
  2. Create a JavaScript function that runs on Document Load
  3. Use HypePetiteVue.createHypeStore(hypeDocument, {...})
  4. Add Vue templates to element Inner HTML
  5. Access $store from your templates

No simulator needed in real Hype - it has the real API!
