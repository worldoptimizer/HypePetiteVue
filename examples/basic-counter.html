Basic Counter Example

A simple counter using HypePetiteVue

{{ count }}
Status: Counter is at zero Counter is positive: {{ count }} Counter is negative: {{ count }}

How it works:

  1. HypePetiteVue.js automatically loads Petite Vue
  2. The v-cloak attribute prevents FOUC (flash of unrendered content)
  3. The v-scope directive creates a reactive scope
  4. The @click directive handles button clicks
  5. The {{ count }} syntax displays reactive data
  6. The v-if/v-else-if/v-else directives handle conditional rendering
